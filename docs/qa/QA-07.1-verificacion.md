## Frontend: pantallas de verificación

Probado con Chrome headless (Playwright) contra la rama de FE-07.1 y el backend
de esta rama, con un arrendador, dos arrendatarios y un REVISOR. Escritorio
(1280×800) y móvil (375×812).

| Id | Caso | Resultado |
|---|---|---|
| F01 | Un `.docx` o un PDF de más de 5 MB muestran el error en el formulario y no hacen ningún POST | ✅ |
| F02 | Con un PDF válido la pantalla pasa a "En revisión" y el formulario desaparece (un solo POST) | ✅ |
| F03 | Con dos pestañas abiertas, el segundo envío muestra "Ya tienes una solicitud en revisión" (409) y en la base queda una sola solicitud | ✅ |
| F04 | El revisor ve la cola con las dos solicitudes y abre el documento (200, `application/pdf`) | ✅ |
| F05 | El revisor rechaza con motivo y aprueba la otra; en móvil, el rechazado ve "Verificación rechazada", el motivo y el formulario para reenviar, y el aprobado ve "Identidad verificada" | ✅ |
| F06 | Las solicitudes decididas salen de la cola del revisor | ✅ |
| F07 | Un arrendador y un arrendatario ven "Acceso restringido" en `/verificacion/revision`, sin botones de decisión | ✅ |
| F08 | Sin sesión, `/api/verificaciones` responde 401; un arrendador ve "Acceso restringido" en `/verificacion` | ✅ |

**Resultado: 8 de 8.** No hubo errores de JavaScript en la consola. Chrome
registra como "Failed to load resource" los 403/404 esperados: la cola con una
cuenta sin permiso, y la consulta de la última solicitud cuando todavía no hay
ninguna.

## Cómo repetirlo

```bash
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/si_be_boilerplate_test?schema=public" npx prisma migrate deploy
npx vitest run --config ./vitest.config.e2e.ts test/qa/qa-07.1-verificacion.e2e-spec.ts --reporter=verbose
```

Para el frontend: backend de esta rama con `npm run db:seed` (crea el
REVISOR), el frontend de FE-07.1 con `API_URL=http://localhost:3000/api/v1`,
y los casos F01 a F08 con un arrendatario en `/verificacion` y el revisor en
`/verificacion/revision`.

## Defectos encontrados

un archivo enviado en un campo distinto de `documento` respondía 500 (multer
