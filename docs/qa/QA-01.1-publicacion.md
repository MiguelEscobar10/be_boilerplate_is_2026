### Sobre "modificación de publicación ajena"

H01 solo pide publicar y consultar; ninguna historia del sprint agrega editar
publicaciones. P17 confirma que no hay ninguna ruta para modificarlas: nadie,
ni el dueño ni otra persona, puede cambiar una publicación. Si más adelante se
agrega la edición, este caso se debe ampliar para que el dueño pueda y otro
arrendador reciba 404.

## Cómo repetirlo

El helper de pruebas agrega `_test` al nombre de la base de `DATABASE_URL`,
así que son dos pasos con URL distintas:

```bash
# 1. Migraciones en la base de pruebas (URL que ya termina en _test)
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/si_be_boilerplate_test?schema=public" npx prisma migrate deploy

# 2. Las pruebas, con la DATABASE_URL normal del .env (el helper usa ..._test)
npx vitest run --config ./vitest.config.e2e.ts test/qa/qa-01.1-publicacion.e2e-spec.ts --reporter=verbose
```
