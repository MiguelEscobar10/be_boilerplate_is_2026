## Cómo repetirlo

```bash
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/si_be_boilerplate_test?schema=public" npx prisma migrate deploy
npx vitest run --config ./vitest.config.e2e.ts test/qa/qa-04.1-solicitudes.e2e-spec.ts --reporter=verbose
```

Para el frontend:
1. Levanta el backend y crea dos solicitudes PENDIENTE que se crucen en el mismo bien.
2. Levanta el frontend con `API_URL=http://localhost:3000/api/v1`.
3. Entra como el arrendador a `/arrendador/solicitudes?estado=PENDIENTE`.
4. Para F05, abre la página en dos pestañas.
